# VoiceSwitch v0.1.0 Release Notes

## 已支持能力

- 菜单栏应用、设置页、日志面板
- Primary IME / Voice IME 配置与校验
- Rust core 最小状态机
- Rust staticlib + C shim + Swift module map FFI bridge
- Option 触发语音切换
- typing 恢复 Primary IME
- 用户手动切换后的 cooldown
- Accessibility 权限降级与重试接管
- 输入法真实切换
- Launch at Login

## 当前行为

- 默认保持 `Primary IME`
- `Option` 进入 `optionPending`
- `optionPendingWindow` 到期后切到 `Voice IME`
- 检测到 typing 后切回 `Primary IME`
- 用户手动切换输入法后进入 `cooldown`
- `cooldownDuration` 到期后恢复自动逻辑
- `voiceExitDelay` 控制从 `voiceActive` 返回 `idlePrimary` 的延迟路径

## 可配置参数

- `optionPendingWindow`
- `cooldownDuration`
- `voiceExitDelay`

## 已知限制

- 不支持按 App 规则切换
- 不支持黑名单
- 不支持浏览器域名规则
- 不支持复杂 typing score
- 不支持设置页配置 `typingKeyWhitelist`
- 长时间 soak test 仍以手工执行为主

## 后续计划

- 更完整的设置项
- 可持久化或更严格 schema 的结构化日志
- 更完整的稳定性验证与发布自动化
- 更丰富的输入行为分类规则
