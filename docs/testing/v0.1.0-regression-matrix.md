## F. 长时间运行检查

这一项当前没有自动化脚本，发布前按下面清单手工执行：

1. 启动菜单栏应用并常驻 `1~2` 小时
2. 重复执行至少 `20` 轮：
   - `Option -> Voice IME`
   - typing -> `Primary IME`
3. 人工执行至少 `10` 轮手动切换，确认 cooldown 重置
4. 期间至少触发 `3` 次权限重试或 Event Tap 重建
5. 观察：
   - 无崩溃
   - 无永久失联
   - 无明显日志风暴
   - 状态不漂移
